# Stratum — Real-Estate Hero Site

Recreation of the single-page Stratum real-estate hero section.

## File Structure

```
index.html                     # the page: inline <style> and one inline <script> IIFE
README.md                      # project documentation
assets/
  fonts/inter-s-400.woff2      # Inter Regular font subset
  fonts/inter-s-700.woff2      # Inter Bold font subset
  fonts/chakra-s-700.woff2     # Chakra Petch Bold font subset
  img/background.webp          # hero background still
  video/background.mp4         # VISION scene video
  video/expression.mp4         # EXPRESSION scene video
  video/craftsmanship.mp4      # CRAFTSMANSHIP scene video
  video/refinement.mp4         # REFINEMENT scene video
  video/balance.mp4            # BALANCE scene video
  video/origin.mp4             # ORIGIN scene video
```

## Running Locally

Serve the directory over HTTP:

```bash
python -m http.server 8080
```

Or open `index.html` directly in any web browser.
